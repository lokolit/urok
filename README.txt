Урок — приложение с виджетом (текущий и следующий урок)

1. Установите Android Studio (бесплатно) и откройте папку UrokApp (File > Open).
2. Дождитесь Gradle Sync (нужен интернет).
3. Подключите телефон Samsung (Параметры > Для разработчиков > Отладка по USB)
   и нажмите Run, либо Build > Build APK(s) и установите файл app-debug.apk.
4. Виджет: долгое нажатие на рабочем столе > Виджеты > Урок.
